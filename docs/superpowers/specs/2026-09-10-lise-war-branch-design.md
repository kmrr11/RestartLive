# 莉瑟与勇者归途主线分支设计

## 目标

在确认与莉瑟交往后、进入魔王城前加入主线重大分支。莉瑟得知勇者胜利后必须回到原世界，提出一起逃跑。玩家决定继续隐藏，或回去重组败退的王国军。不存在免除分别的第三条路。

## 数据流

2026-09-15 已接入同一条 `isekai_arc`，不另起独立故事。顺序为 `iw_true_page` → `iw_lise_confession` → `lise_contract` → `lise_war_choice`，位于 `iw_castle` 前。

主动告白入口要求至少 16 岁、已认识莉瑟、已接受勇者身份、未交往且未分手。好感基础门槛为 35，沿用选择判定的运气修正。成功写入 `confessed_lise` 和 `together_lise`；未告白或被拒则继续原主线。已有有效交往关系跳过重复告白，直接获知契约。

逃跑提议要求 `iw_hero`、`confessed_lise`、`together_lise` 且无 `apart_lise`。选择逃跑后经过短暂共同生活、北关失守、河防失守与伤兵到来，再抵达 `lise_escape_decision`；这里仅由玩家选择继续隐藏或回归。前线败退添加 `kingdom_retreat`。

隐藏路线经过王国陷落与边境余生，最终 `lise_hidden_end` 添加 `lise_hidden_life`，结算为异世界相伴至老的人生结局，不重新进入现代日常事件池。回归路线添加 `lise_return_front`，经过残军集结、补给或召回散兵、河岸反攻后进入最终攻城。最初拒绝逃跑的路线直接前往攻城准备，不会虚构逃亡或败退经历。

两条讨伐路线均在 `lise_victory` 击败魔王，经过契约确认、告别选择、松手与归乡。`lise_release` 添加 `apart_lise` 与 `lise_farewell_memory`，移除 `together_lise` 和 `bond_lise`；`lise_home` 回到现代人生。传记及关系阶段显示异界离别。战时停用原先的轻松旅途随机插曲。

## 性格与结局

莉瑟只提出逃跑，不替玩家做战略决定。逃跑路线体现她用吐槽掩饰害怕；回归路线体现她在战前计算撤退路线、战后反复确认传送门规则，并把备用地图、信标和未完成魔法页交给玩家。两条路线都以关系后果结束，回归路线明确发生分别。

## 验证

`tools/LifeSim.Checks/LiseStoryChecks.cs` 从真实人生入口验证隐藏、回归、直接讨伐、不告白、非勇者路线，分支节点与选择等待状态均重放存档；额外状态夹具验证低好感被拒、已有恋人、已经分手。补给/散兵、破阵/掩护、拥抱/言别的选项均覆盖。
