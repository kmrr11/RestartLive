# 莉瑟魔王城前主线分支实施计划

目标：完成已确认的主线分歧。莉瑟提出逃跑，逃跑导致王国败退；玩家只能选择继续隐藏或回归战线。击败魔王必然归乡，恋人分别。

实现：在 isekai_arc 的 iw_true_page 与 iw_castle 之间接入剧情内主动告白、契约揭示和逃跑提议。分支继续使用同一故事的 gotoStep / nextStepId，避免季节随机事件破坏顺序。拒绝告白或不接受勇者身份继续原路线。

- [x] 先添加失败测试：真实主线抵达入口；不告白、低好感被拒、已有恋人、已分手、非勇者的入口隔离；隐藏、回归、直接讨伐三条终局及每步回放。
- [x] 在 StorySteps.csv 增加明确串联的告白、逃跑、两次败退、玩家抉择、重组、反攻、击败魔王及告别节点。在 Branches.csv 增加专属选择，修正旧孤立选择的目标。
- [x] 隐藏结局以在异世界度过余生结束本局，避免落回现代普通事件。回归终局返回现代，清理交往标记并保留离别记忆；传记呈现两种结局。
- [x] 同步两个 Resources 镜像。检查所有新增节点的引用、可达性和旧主线出口；跑测试与 UnityCompile 检查。

告白入口：成年、认识莉瑟、接受勇者身份，且尚未交往或分手。主动告白以好感 35 为基础门槛，沿用选择判定的运气修正；成功才写入 confessed_lise 和 together_lise。已有有效交往关系跳过重复告白。

隐藏终局：王国陷落，玩家隐藏勇者身份，与莉瑟在边境度过余生；没有击败魔王，没有返回现代。回归/继续讨伐终局：击败魔王，契约生效，无法让莉瑟同行或通过封印绕过归乡。

验证边界：核心测试使用生产逻辑与 Unity API 替身；不等同于 Unity 编辑器画面试玩。
